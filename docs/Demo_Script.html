    ① 每次只能移动 top disk（LIFO 特性）

    ③ 非法移动不进计数器 —— 这是作业评分点

 

    💬 20 分钟 Challenge 是 连续的，什么操作都不能暂停它。

你说的话

💬 这 7 步就是递归算法生成的 最优解 —— 2³ − 1 = 7。

    3 盘 7 步，4 盘 15 步，5 盘 31 步。指数增长！

 

    💬 递归核心思想：分治

    ① 把 n−1 个 disk 从 源 → Spare（递归解决子问题）

    ② 把最大的 disk 直接 源 → 目标（一步搞定）

    ③ 把 n−1 个 disk 从 Spare → 目标（再递归）

 

    💬 关键看计时器 —— 进入 Learning Mode 后它还在走！

    这是作业硬性要求，我用 setInterval 独立运行实现的。

Theory Box 里的三个公式（念出来）
2ⁿ − 1
最优步数公式（Minimal Moves）
T(n) = 2T(n−1) + 1
递归关系（Recurrence Relation）
Base: T(1) = 1
只有 1 个 disk 时只需 1 步
Complexity → O(2ⁿ)
指数级！n 大了解不动

// ① Stack ADT —— 先讲数据结构
class Stack {
  push(item)    // O(1) — 放 disk 上去
  pop()       // O(1) — 拿走 top disk
  peek()      // O(1) — 查看不拿
  isEmpty()  // O(1) — 空不空
}
// 四个操作全是 O(1)，因为 JS 数组 push/pop 是常量时间
💡 讲解点：Stack ADT 的美妙之处 — 四个操作全 O(1)。这就是为什么 peg 天然就是 Stack。

// ④ 递归求解器 —— 核心算法，三行递归！
function solve(n, from, to, via) {
  if (n === 1) {
    moves.push({from, to});          // Base case
  } else {
    solve(n-1, from, via, to);       // 搬 n-1 到 spare
    moves.push({from, to});           // 搬最大的
    solve(n-1, via, to, from);       // 搬 n-1 到 target
  }
}
// solve(3,'A','C','B') → 自动生成全部 7 步最优解 🤯

// ⑤ 计时器 —— 为什么 Learning Mode 不会暂停它
function startTimer() {
  gameState.timerInterval = setInterval(() => {
    gameState.challengeTimeLeft--;    // 每秒 -1
    if (剩下 5 分钟) → 橙色警告
    if (剩下 1 分钟) → 红色警告
    if (到 00:00) → Time's up modal
  }, 1000);
}
// setInterval 独立运行，和 learningMode flag 完全解耦

Part 5 — 挑战 & 反思
你说的话

💬 做这个项目我遇到 三个主要挑战：

 

    ① 状态同步 — Undo / Hint / Restart / 难度切换

        全都要改 gameState。状态不一致就出 bug。

        我的解法：所有可变状态集中到一个 gameState 对象。

 

    ② 计时器和 Learning Mode 隔离 —— 作业明确说不能停

        我的解法：setInterval 独立跑，和 mode 完全解耦。

 

    ③ Disk 叠放位置 —— 不同难度 disk 数变，bottom offset 要算对

        我的解法：CSS class pos-0 / pos-1 / pos-2 统一处理。

 

💬 最大的收获：把物理 peg 建模成 Stack 后，

    所有业务逻辑突然都清晰了 —— 这就是数据结构的力量。
